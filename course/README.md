# Course notes

Notes, experiments and exercises from *The Complete Bash Scripting Course – Full Length Guide to Learning the Bash Shell* by You Suck at Programming ([watch on YouTube](https://www.youtube.com/watch?v=Sx9zG7wa4FA)).

Each numbered folder holds the scripts and notes for one chapter. Most files are small, runnable scripts with comments written while following along.

| # | Topics |
|---|--------|
| [01](01/README.md) | The terminal, REPL, aliases, `man`, `grep`, pipelines, paging, renaming |
| [02](02/README.md) | Variables, `PATH`, permissions, naming, a vim crash course |
| [03](03/README.md) | First scripts: loops, input/output, functions, conditionals |
| [04](04/README.md) | Arithmetic, arrays, associative arrays, command & process substitution, `IFS`, `shift`, subshells |
| [05](05/README.md) | `cut` and `tr` |
| [06](06/README.md) | Script arguments, pipe status, `time` |
| [07](07/README.md) | Functions, return vs output, sourcing code, `{}` vs `()` |
| [08](08/README.md) | Parameter expansion, replacements, array expansion |
| [09](09/README.md) | Globbing, glob options, extended globbing |
| [10](10/README.md) | Brace expansion |
| [11](11/README.md) | `printf`, date formats, `mapfile`, regex |
| [12](12/README.md) | `test` vs `[` vs `[[` |
| [13](13/README.md) | Named pipes, `trap` and signals |
| [14](14/README.md) | Cursor control, `isatty`, colours |
| [15](15/README.md) | Customising `.bashrc`, readline |
| [16](16/README.md) | Aliases with arguments, ANSI string length |
| [17](17/README.md) | Fork bomb (explained, do not run) |
