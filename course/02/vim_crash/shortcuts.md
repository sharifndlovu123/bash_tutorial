# Vim shortcuts

See the full table in [`../README.md`](../README.md#vim-crash-course). Practice with `file.txt` and `script.sh` in this folder:

```bash
vim file.txt
```

| Mode | Enter with | Purpose |
|------|------------|---------|
| Normal | `Esc` | read, navigate, run commands |
| Insert | `i` | edit text |

| Normal-mode command | Action |
|---------------------|--------|
| `dd` | delete line (cut) |
| `yy` | yank (copy) line |
| `p` | paste |
| `o` / `O` | new line below / above and enter insert mode |
| `u` | undo |
| `.` | repeat previous command |
| `:w` / `:q` | write / quit |
